# الأدوار والصلاحيات

| الدور | الصلاحية في Phase 1 |
|---|---|
| admin | جميع الجداول، المستخدمون، الأدوار، الأخبار والوسائط |
| editor | الأخبار والصفحات والبرامج والدورات؛ لا يدير الأدوار |
| faculty | ملفه وسجلاته المرتبطة فقط |
| admissions | طلبات القبول والوثائق الخاصة فقط |
| library_editor | الإصدارات والمجلة والأبحاث والمكتبة والمواقع والوسائط |
| student | ملفه الشخصي فقط |
| public | قراءة المحتوى المنشور والظاهر فقط |

التحقق مزدوج: Proxy يمنع التنقل غير المصرح، وRLS/Server Actions تفرض الصلاحية على الخادم. إخفاء الأزرار ليس آلية حماية.

وظائف قاعدة البيانات: `has_role`, `has_any_role`, `is_admin`, `current_profile_id`. كلها `SECURITY DEFINER` مع `search_path` مقيد.
